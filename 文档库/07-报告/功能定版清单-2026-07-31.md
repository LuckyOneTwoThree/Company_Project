## 二、产品形态与架构总览

**Node = 纯 Web3 自管钱包与数字通行证中枢**，C 端 App 由 5 大 Tab 构成。

```
Tab1 钱包 ── 资产看板 / Swap / 发送接收 / 钱包管理
Tab2 团队 ── 推广中心 / 我的团队（积分等级）/ 邀请中心 / 佣金明细
Tab3 交易·商城 ── 统一商品池 / 直购 / 订单 / 短号中心 / 持有码 / 流转市场
Tab4 应用中心 ── 应用上架 / 下载更新 / 品类导航
Tab5 身份 ── 福利特权 / 保险库 L1 / DID 通行证
```

**产品三大铁律**（所有功能不可违背）：
1. 私钥永不上链、永不上云（本地加密 + 设备指纹硬约束）
2. 关系永久、迁移受限（上下级 set-once，唯一可动口子为多签治理与地址迁移）
3. 地址即身份（算钱/绑定/鉴权只信链上地址，短号/Web2 凭证仅辅助）

## 三、已实现功能清单（本次定版范围 · ✅）

### Tab 1 · 钱包（纯资产操作，不混入业务/关系/推广）

| 功能 | 关键规则 |
|------|----------|
| 自管钱包管理 | 创建 / 导入 / 重命名 / 导出私钥（PIN + 明文警告）/ 销毁，完整自管闭环 |
| 资产看板 | 总估值 + 代币明细（RC / USDRs / HRCs / RSTs） |
| Swap 兑换 | 自建 AMM 两代路由 + 滑点保护 4 档 + 白名单分级（HRCs 需 rank≥3；大额按等级或持仓双维度） |
| 发送 / 接收 | 链上转账（收发） |
| 代币体系 | RC（Gas）/ USDRs（平台主币）/ HRCs（生态联合）/ RSTs（储备）；计价用 USDT，结算用 USDRs |

> 水龙头已移除，后续调整为社区制任务激励（见第四节）。

### Tab 2 · 团队（Aeon R9 永久关系网络）

> **硬前置**：所有团队能力依赖**设备指纹绑定**（保险库 L1 提供），一台设备同时刻只绑一个钱包。

| 功能 | 关键规则 |
|------|----------|
| 永久关系绑定（5 渠道归因） | 扫码 > 搜索短号 > 邀请链接(30天窗口) > 团队申请 > 孤儿池；链上 set-once 不可改 |
| 推广中心 | 上级短号/我的短号两段式布局 + 二维码/邀请/团队申请三按钮 |
| 我的团队 | 上下级关系树 + **积分等级制度**（个人积分 / 团队积分双轨 + rank 1-10 升级门槛 + miner 审核升级） |
| 邀请中心 | 定向邀请（30 天窗口）+ 状态机 + 历史记录 |
| 佣金明细 | L1/L2/L3 分账 + 多币（USDRs/RC/HRCs）可领取 + 一键领取 + 合约明细 + 按月/周统计 |
| 级差返利 | 沿上线链取 3 层，每层按该层上线"自己的等级 rank"派发返利 |
| 动态压缩 | 上线 rank=0 自动跳过，名额上卷给合格上线（返利总名额恒为 3 层，maxSkips=20） |
| 双积分体系 | 个人积分（basis=0，L1→L2 升级燃料）+ 团队积分（basis=1，L3+ 升级燃料），独立计算、不可互替 |
| 返佣冻结期 | 成交即分配但冻结：单价<500U 冻 7 天、500–2000U 冻 14 天、≥2000U 冻 30 天；退货只退钱不解除关系 |

> 关系转移 / 地址迁移（含换地址迁移、多签治理迁移）本版未上线，见第四节。

### Tab 3 · 交易·商城（统一商品池 + 级差返利）

> **硬前置**：①设备指纹绑定 ②团队身份绑定（游客可浏览，下单前必须绑定）。

**商城核心**

| 功能 | 关键规则 |
|------|----------|
| 统一商品池 | 仅官方上架（onlyMiner）、全平台同价、统一库存（破除传统分级商城层级割裂） |
| 商品模型 | 4 类商品（实物 / 虚拟卡密 / 级别服务 / 积分）+ 多币定价 + 阶梯数量折扣 + 保密商品（链上存哈希）+ 直写奖励 |
| 直购下单 | 黑白名单 + MOQ + 阶梯算价 + 收款 + 唯一码分配 + 直写奖励 + 积分 mint + 级差返利触发 |
| 级差返利 | 购买触发沿上线链 3 层分润 + rank×layer 矩阵 + 动态压缩 + 多币路由 + 安全护栏 |
| 代理能力商品 | 采购推广工具与服务，获得发展下级的白名单权限；**非入门费**，不购买不影响钱包/浏览/购买 |

**订单与退货**

| 功能 | 关键规则 |
|------|----------|
| 唯一码库存 | 状态机 0/1/2/3（未设→可售→已售→已退，已退永久作废）；保密商品链上仅存哈希 |
| 订单管理 | 主辅分离（主 4 态 + 实物物流/虚拟卡密辅态）+ 订单 Tab（全部/进行中/已完成/退货） |
| 退货流程 | returnRequest + 已领奖励先退回 + miner approveReturn/rejectReturn + revokeOrder |
| 收货地址 | 新增/编辑/删除/设默认 + 结算页自动回填 |
| 二手转卖 | transferItem（直转）+ listItem/buyListed（挂单，收 resaleFeeBps） |

**短号中心**

| 功能 | 关键规则 |
|------|----------|
| 💾 我的短号 | 列出已绑短号 + 设为展示短号 |
| 💎 购买靓号 | 位数筛选（5/6/7/8 位）+ 查价 + 推荐；5 位基价 1000U 每多一位 ×0.9，豹子×50/顺子×20/四连同×10/葫芦×8/双对×5/吉尾×3 |
| 🎁 免费号 | 随机生成 10 个 10-12 位候选 + 换一批 + 领取（每身份仅 1 次） |
| 转移 / 赠送 | 即时过户（同网络限制，跨网络拦截） |

**流转市场（二级资产处置）**

| 渠道 | 合约 | 手续费 | 关键规则 |
|------|------|--------|----------|
| 一口价 | FixedPriceMarket | 0% | 二级市场主渠道，快速变现 |
| 拍卖 | AuctionHouse | 2.5% | 高价资产竞价，含 forceSettle/forceCancel/withdrawRefund |
| 赠送 | GiftChannel | 号主付手续费 | 即时过户，不在挂单弹窗暴露，订单中心可见记录 |

> **铁律**：二级市场流水不触发归因、不触发分润；lockSku 跨渠道锁；统一台账 TradeLedger。
> 租赁（RentalChannel，ERC-4907）本版未上线，见第四节。

### Tab 4 · 应用中心（第三方应用分发）

| 功能 | 关键规则 |
|------|----------|
| 应用上架 | 合作方提交上架申请 + 资质审核 + 签署协议 + 上架到应用中心 |
| 应用下载 / 更新 | 用户直接下载 / 更新已上架应用 |
| 品类导航 | 5 大品类（官方精选 / IM 社交 / 跨境电商 / Web3 类 / 我的）+ 金刚位 |
| 平台差异 | iOS 跳 App Store / Android 分发 APK；深链 Universal Links / App Links |
| 我的 | 最近打开历史 + 上架申请入口 |

> 抽成结算体系（CPS + 上架费）🟡 开发中，费率待定，见第四节。

### Tab 5 · 身份（Web3 权益与凭证聚合）

| 功能 | 关键规则 |
|------|----------|
| 福利特权 | 空投 / 资产 / 互动 三类入口；多合约设计（跨链/分批发放）+ 一键领取；所有领取需经设备指纹绑定校验 |
| 保险库 L1（安全基座） | 设备指纹钥匙：待激活/已激活两阶段 + 一台设备同时刻只绑一个钱包 + 冷密钥基于设备指纹生成、私钥永不上传 + 激活后解绑需 500 USDT |
| 全模块前置闸门 | 福利/团队/商城/身份关键操作前强制校验设备指纹（逻辑链：设备指纹 → 团队绑定 → 商城购买） |
| DID 通行证（被动授权） | 第三方 App 拉起 Node 授权面板 → 选签名主体（Web3 地址 / Web2 凭证）→ 6 位 PIN → 本地私钥签名 → 返回凭证登录（EIP-712） |
| 身份凭证中心 | App 列表页（按应用维度展示数字身份概览）+ App 身份管理页（Web3 钱包/Web2 账号 Tab 切换 + 网络筛选） |
| Web3 钱包注入 | 网络选择 → 钱包选择 → 确认注入 |

> 云端绝不存储"地址↔Web2 账号"映射；首期仅"被动授权"模式。
> L2（人脸+硬件）/ L3（DNA）规划中，见第四节。
