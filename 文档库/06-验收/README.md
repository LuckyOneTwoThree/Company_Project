# 验收文档

> 按版本/阶段集中存放验收相关文档。量大且独立成目录。
> 命名规则:`v{版本号}-{类型}.md`,如 `v1.2-验收方案.md`、`v1.2-验收报告.md`。

## 建议子结构

每版一批,建议按版本组织(也可扁平命名):

```
验收/
├── v1.0/
│   ├── 验收方案.md          # 事前:测试方案/UAT 计划/验收标准清单
│   ├── 验收清单.md          # 事中:逐项验收检查表(AC 对应)
│   ├── 验收报告.md          # 事后:验收结论、通过/不通过、遗留问题
│   └── 问题追踪.md          # 事中事后:验收发现的问题及修复跟踪
├── v1.1/
│   └── ...
```

## 文档类型说明

| 类型 | 时机 | 内容 |
|------|------|------|
| 验收方案 | 事前 | 测试范围、UAT 计划、验收标准(对应 PRD 的 AC) |
| 验收清单 | 事中 | 逐项检查表,每条 AC 的通过状态 |
| 验收报告 | 事后 | 结论、遗留问题、上线建议 |
| 问题追踪 | 事中事后 | 验收发现的问题、责任人、修复状态 |

## 与其他文件的关系

- **验收标准来源**:`文档库/01-需求/` 下的 PRD(AC 清单)
- **验收结论去向**:记入 `记忆/进度日志.md`(里程碑状态变更时);关键结论同步到 `现状.md`
- **验收中发现的风险**:登记到 `项目管理/风险登记册.md`
- **验收相关决策**(如是否上线):记入 `记忆/决策记录.md`
