# Node 产品架构蓝图 v4.2 设计方案

> **版本** v4.2 ｜ **日期** 2026-08-05 ｜ **定位** 循环驱动视角·内部耦合+飞轮联动
> **核心主线** 链运营·技术生态开放

---

## 一、产品定位：链运营·技术生态开放

### 自治
- 技术/gas/合约/业务参数完全自治
- 社区自治·自治主权
- 业务层完全自治调整参数

### 连接
- 人关系连接
- 资产连接·生态连接·应用连接
- 全球化·可跨域

### 共享（融入技术生态开放）
- **渠道共享**：关系网对生态伙伴开放
- **关系网共享**：用户流量作为分发渠道
- **技术生态开放**：公链逻辑·开发/合约/RPC节点不限制·服务器可接入OPS
- **开放生态**：全球化·跨域连接

### 永续
- 硬件身份DID唯一
- 关系永不变·传承传递
- 存储·信托机制

## 二、生态循环（连接+共享）

### 2.1 生态参与方（4类·对应耦合模块）

| 参与方 | 贡献 | 获益 | 耦合模块 |
|---|---|---|---|
| **应用开发者** | 上架应用·内容运营 | 分发抽成·关系网流量 | → 应用中心生态 |
| **品牌商/供货方** | 商品供应·信任背书 | 零获客分销·真实归因 | → 统一商品池 |
| **代理/推广者** | 渠道资源·团队管理 | 级差分润·渠道权益 | → 关系网络 |
| **普通用户** | 消费·关系绑定·应用使用 | 商品·返利·福利·资产 | → 身份基座+交易 |

### 2.2 业务模块（被耦合的载体）

#### ① 应用中心生态
- 应用上架·四道审核·签协议定抽成
- 分发抽成T+7/推广位T+30/交易抽成T+30/生态联合
- 流量出口·纯平台抽成·不进多级分账

#### ② 统一商品池
- 仅官方上架·全平台同价·官方管库存
- 四类商品：实物/虚拟/级别服务/积分
- 唯一码体系：未设→可售→已售→已退(永久作废)
- 下单硬前置：必须绑定团队

#### ③ 关系网络
- 永久绑定·不可篡改·随地址迁移
- 5渠道归因：扫码 > 搜索短号 > 邀请 > 团队申请 > 孤儿池
- 3层级差返利·动态压缩(跳过未达标)
- 返佣冻结期：7/14/30天分档(防套利)

#### ④ 身份基座
- DID：地址即身份·被动授权登录
- 设备指纹：一机一身份·反女巫闸门
- 保险库：L1已上线 / L2L3规划·多钥匙分级
- 福利特权：空投+资产福利+互动福利(指纹校验)

### 2.3 共享主线
- **渠道共享**：关系网对生态伙伴开放·流量对开发者开放
- **关系网共享**：用户流量作为分发渠道
- **技术生态开放**：DID通行证·应用接入·API·不托管不撮合

### 2.4 生态循环内部耦合（7条）

| 编号 | 耦合线 | 驱动逻辑 |
|---|---|---|
| ① | 应用开发者 → 应用中心生态 | 上架应用,丰富生态 |
| ② | 品牌商 → 统一商品池 | 上架商品,驱动交易 |
| ③ | 代理 → 关系网络 | 绑定下级,扩大网络 |
| ④ | 用户 → 身份基座 | 设备指纹,信任底座 |
| ⑤ | 应用中心生态 ↔ 关系网络 | 双向导流 |
| ⑥ | 统一商品池 → 关系网络 | 成交触发返利链 |
| ⑦ | 身份基座 → 覆盖全参与方 | 前置闸门 |

### 2.5 Miner 归属说明
- Miner 放**平台运营侧**，不放生态参与方
- 职责：审核退货·配置挖矿规则·渠道开关·强制撤单
- 是**平台治理工具**，不是外部贡献者

## 三、资产循环（自治+永续）

### 3.1 资产层（唯一码所有权登记）

#### ① 商品发行（官方统一商品池）
- 实物/虚拟/服务/积分·唯一码库存
- 一级购买触发返利/积分/返利分配

#### ② 短号发行中心
- 靓号：5位基价1000×号型加成(纯毛利)
- 免费号：10-12位·每身份领一次
- 地址=真身,短号=可交易别名

#### ③ 资产化确权
- 锁定→确权解锁·防双花
- 资产权属登记：代码所有权与商品所有权分离

#### ④ 通证化（规划·合规前置）
- 资产上链交易·需法务前置

### 3.2 获取渠道层（7个渠道）

| 渠道 | 状态 | 机制 |
|---|---|---|
| 一级购买 | 已落地 | 购买即触发返利链 |
| 赠送 | 已落地 | 号主付费·即时过户 |
| 一口价 | 已落地 | 0%手续费·引流二级市场 |
| 拍卖 | 开发中 | 竞价拍卖·2.5%手续费 |
| 租赁 | 开发中 | 使用权与所有权分离·按协议 |
| 集邮挖矿 | 已落地 | 持有指定资产→兑换奖励商品 |
| 荷兰拍/限时交易所 | 规划中 | 动态价格交割 |

### 3.3 资产转移与信托（永续主线·新增）

#### ⑤ 资产转移
- 跨账户转移(权属变更·含继承/交易/赠予)
- 跨域跨链转移(全球化连接)
- 传承传递(继承人指定+触发条件)
- ⚠ 法律效力待定·需法务前置

#### ⑥ 存储信托
- 托管(钥匙管理·多钥匙分级授权)
- 信托契约(条件释放·遗产继承)
- 高级托管(L3强生物特征·大额托管)
- ⚠ 法律效力待定·需法务前置

### 3.4 统一台账
- 所有获取渠道(含一级)统一写一张链上订单表
- 订单·商品·渠道·买卖双方·币种·价格·时间全记录
- 退货记反向单(冲销)

### 3.5 资产循环内部耦合（6条）

| 编号 | 耦合线 | 驱动逻辑 |
|---|---|---|
| ① | 商品发行 → 资产化确权 | 发行即确权 |
| ② | 资产化 → 获取渠道 | 确权后可流转 |
| ③ | 一级购买 → 关系网络 | 触发返利链·飞轮① |
| ④ | 获取渠道 → 统一台账 | 所有渠道统一记账 |
| ⑤ | 资产转移 ↔ 存储信托 | 转移触发信托·信托保护转移 |
| ⑥ | 资产转移/信托 → 节点经济 | 信托服务费·规划 |

### 3.6 关键边界
- 二级市场所有渠道流水**一律不进级差返利**(资产处置≠团队裂变)
- 二级市场**不强制团队绑定**(处置归流转市场,不归交易)
- 碎片化流转**明确不启动**(合规风险过高)

## 四、收益循环（永续+共享）

### 4.1 第一层：平台运营侧创收（钱从外部进来）

| 创收线 | 状态 | 机制 | 结算 |
|---|---|---|---|
| 官方商品池交易 | 已落地 | 商品毛利·级差返利属分销成本 | 成交即结算 |
| 靓号发行 | 已落地 | 5位基价1000×号型加成·纯毛利 | 成交即结算 |
| 二级市场手续费 | 开发中 | 拍卖2.5%/一口价0%引流/租赁按协议 | 成交即结算 |
| 应用中心抽成 | 开发中 | 分发T+7/推广位T+30/交易抽成T+30 | 周期结算 |
| 短号与权益位售卖 | 已落地 | 靓号定价模型+权益位 | 成交即结算 |
| 生态联合 | 规划中 | 跨生态合作·联合空投 | 按协议 |

### 4.2 第二层：参与者侧收益（钱在生态内部分配）

#### ① 购买获得权益（普通用户）
- 商品本身
- 团队积分(升级燃料)
- 返利资格

#### ② 代理分销返佣【分销-代理-返利·内部业务线】
- 3层级差返利·按上线等级与层级取返利比例
- 动态压缩(跳过未达标·名额上卷)
- 返佣冻结期7/14/30天分档
- 退货：只退钱不解除关系·已领佣金从后续抵扣

#### ③ 团队积分转移（高级代理）
- 单次≤30%·单月≤50%·转入不可升级仅消耗
- 链上留痕

#### ④ 二级市场转售（资产持有者）
- 一口价差价
- 拍卖差价
- 租赁租金

#### ⑤ 福利领取（符合条件用户）
- 空投福利(USDRs/HRCs)
- 资产福利(体验商品/试用/卡券)
- 互动福利(签到/任务/活动)

### 4.3 第三层：节点经济（纯规划方向·独立标注）

> 说明：本层只保留**当前体系无对应实现的规划项**。已落地能力归位到对应循环：
> - 集邮挖矿 → 归资产循环获取渠道（已落地）
> - 分销商业收益 → 归第二层参与者侧"代理分销返佣"（已落地，同源）

| 类型 | 状态 | 说明 |
|---|---|---|
| 节点服务器/RPC | 规划 | 概念：节点运营者提供服务·获得服务分成·当前体系无对应实现 |
| 硬件手机P2P | 规划 | 概念：闲置算力变现·贡献度计量·当前体系无对应实现 |

### 4.4 收益循环内部耦合（4条）

| 编号 | 耦合线 | 驱动逻辑 |
|---|---|---|
| ① | 平台创收 → 参与者收益 | 成交触发返利·飞轮② |
| ② | 参与者收益 ↔ 等级体系 | 返利↔等级双向促进 |
| ③ | 参与者收益 → 价值捕获 | 收益沉淀为平台商业价值 |
| ④ | 节点经济(规划) → 价值捕获 | 未来节点服务创收（仅规划项：节点服务器/RPC、硬件手机P2P） |

### 4.5 关键边界
- 级差返利与多级佣金是**分销成本**，不是平台净收入
- 一口价0%手续费是**刻意的引流设计**(先把流动性做起来)
- 节点服务器/RPC/硬件手机P2P是**规划方向**，当前体系无对应实现

## 五、三循环飞轮联动（外部耦合）

| 飞轮 | 驱动方向 | 驱动逻辑 |
|---|---|---|
| ① | 生态 → 资产 | 关系网带流量 → 商品成交 |
| ② | 资产 → 收益 | 购买触发返利 → 流转产生手续费 |
| ③ | 收益 → 生态 | 返利激励扩张关系网 → 节点经济吸引参与方 |

**支撑体系：**
- **身份基座**：支撑全循环(前置闸门)
- **基础层**：托底全循环(钱包/代币/链节点/存储)
- **明确边界**：三铁律+合规上限(覆盖全循环)

---

## 六、明确边界

### 6.1 三铁律
1. 私钥永不上链·永不上云
2. 关系永久·且只能随地址迁移
3. 地址即身份

### 6.2 合规上限
- 返利≤3层
- 严禁拉新计酬
- 代币不承诺增值/回购/做市

### 6.3 明确不启动
- 交易碎片化流转(合规风险过高)

### 6.4 产品红线
- 不托管用户私钥
- 不做加密货币撮合交易
- 不内嵌DApp浏览器

---

## 七、基础层

- 自管钱包(私钥自持)
- 代币体系(四币双轨·无门槛兑换·熔断)
- 链与合约运行环境(RPC开放·多签治理)
- 数据存储与索引
- 返利资金池(100%真实毛利)

## 八、角色与价值流

### 8.1 普通用户
- **投入**：消费·关系绑定·应用使用·设备持有
- **获得**：商品·级差返利·福利·资产所有权
- **付费点**：商品价款·转售手续费·短号·会员

### 8.2 生态伙伴/分销商
- **投入**：渠道资源·关系网·团队管理
- **获得**：级差分润·渠道权益·等级加成
- **付费点**：入驻保证金·高级权益位

### 8.3 应用开发者
- **投入**：应用开发·内容运营·合规材料
- **获得**：关系网流量·支付/身份·分成收入
- **付费点**：应用抽成·上架审核费

### 8.4 品牌商/供货方
- **投入**：商品供应·信任背书
- **获得**：零获客分销·真实交易归因
- **付费点**：代销分润·佣金

### 8.5 Miner（平台运营审核角色）
- **职责**：审核退货·配置挖矿规则·渠道开关·强制撤单
- **定位**：平台治理工具·非外部贡献者

### 8.6 平台（Node）
- **投入**：基础设施研发·链运营成本·合规投入·生态冷启动补贴·硬件研发
- **提供**：身份·关系账本·结算·市场·合规·审核
- **获得**：佣金·手续费·抽成·服务费·靓号毛利

## 九、路线图与启动序列

### 阶段1 · 最小商业闭环MVP 已落地
- 团队等级+关系网(永久绑定·5渠道归因)
- 多级返利(3层级差·动态压缩)
- 统一商品池(官方上架·唯一码)
- 结算(成交即结算·返佣冻结期)
- **验证指标**：闭环跑通·返利链路可验证

### 阶段2 · 生态开放 开发中
- 二级市场三渠道(一口价·拍卖·租赁)
- 应用中心第三方分发+抽成结算
- DID打通首批第三方应用
- **限制**：碎片化流转不启动
- **验证指标**：二级市场流动性·应用上架数

### 阶段3 · 治理开放 规划中
- 保险库L2/L3(生物特征钥匙)
- 资产转移与信托(需法务前置)
- 通证化(需合规结论)
- 社区自治机制(投票·参数·仲裁)
- **验证指标**：信托服务落地·治理参与度

### 阶段4 · 全球化跨域 规划中
- 跨域跨链转移
- 生态联合(跨生态合作·联合空投)
- AI Agent融入客服·风控·推广
- **限制**：分区域合规运营
- **验证指标**：跨链资产流转·生态合作数
