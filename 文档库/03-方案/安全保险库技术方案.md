## 架构总览

安全保险库采用"钥匙(鉴权)与保险柜解耦绑定"的分层架构：

```

│                        应用层 (App)                          │

└─────────┼────────────────┼────────────────────┼─────────────┘

┌─────────▼────────────────▼────────────────────▼─────────────┐
│                   保险柜服务层 (Vault Services)               │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │  虚拟权益舱   │  │ 数字代币托管舱│  │   智能信托继承协议   │  │
│  │   (L1钥匙)   │  │  (L2钥匙)   │  │     (L3钥匙)       │  │
```

## 第一阶段：基础框架（当前开发中）

### 核心流程

1. **设备指纹采集**
   - 采集设备硬件特征（CPU、内存、存储、网络等）
   - 生成复合哈希作为设备唯一标识
   - 同一设备指纹一致，不同设备指纹不同

2. **设备指纹钥匙绑定**
   - 用户授权后，将设备指纹与IM用户账号绑定
   - 服务端记录绑定关系

3. **冷密钥生成**
   - 基于设备指纹生成ECC非对称密钥对
   - 私钥本地加密存储（Keychain/Keystore）
   - 公钥上传服务端用于后续校验

4. **虚拟权益舱保护**
   - 权益发放时校验设备指纹钥匙 + 冷密钥签名
   - 确保单设备单钱包排他性，防止批量薅羊毛

### 两阶段生命周期

| 指纹状态 | 触发条件 | 链上状态 | 撤销/解绑规则 |
|----------|----------|----------|---------------|
| 待激活(Pseudo-bound) | 在保险库完成本地签名向导 | 本地存根(未上链) | 完全免费，无冷却期，随时撤销更换钱包 |
| 已激活(Activated) | 首次在福利中心成功领取任一福利 | 广播存证(已写入智能合约) | 必须支付500 USDT服务费解绑，解绑后设备无冷却 |

### 状态恢复校验逻辑（防重装/重置）

- 校验时机：绑定向导 Step 1 点击下一步时触发
- 校验逻辑：用当前设备硬件Hash向区块链查询历史绑定记录
  - 无历史记录 → 放行进入全新绑定流程
  - 有活跃链上存证 → 拉取链上绑定钱包地址，与本地导入钱包列表比对
    - 本地已导入匹配钱包 → 自动恢复指纹卡片，跳转至Step 4
    - 本地未导入匹配钱包 → 拦截，提示导入原绑定钱包私钥

### 接口设计（规划中）

| 接口 | 方法 | 说明 |
|------|------|------|
| /vault/device/bind | POST | 绑定设备指纹钥匙 |
| /vault/device/unbind | POST | 解绑设备指纹钥匙 |
| /vault/device/verify | POST | 校验设备指纹有效性 |
| /vault/coldkey/generate | POST | 生成冷密钥对 |
| /vault/coldkey/publickey | GET | 获取公钥 |
| /vault/claim/verify | POST | 权益领取校验 |

## 第二阶段：多模态钥匙矩阵（规划中）

| 钥匙类型 | 技术实现 | 安全等级 |
|----------|----------|----------|
| 设备指纹钥匙 | 本地硬件特征哈希 | L1 |
| 人脸/虹膜生物钥匙 | iOS Secure Enclave / Android Biometric API | L2 |
| 硬件安全芯片钥匙 | TPM 2.0 / 外部智能密码卡 | L2 |
| DNA生物特征钥匙 | DNA多维度哈希映射 + 非对称多签 | L3 |

## 第三阶段：保险柜服务舱矩阵（规划中）

| 服务舱 | 最低钥匙要求 | 业务场景 |
|--------|-------------|----------|
| 虚拟权益舱 | L1 | 积分、白名单、卡券 |
| 数字代币托管舱 | L2 | 稳定币、通证管理 |
| 永久性冷数据加密存储 | L2 | 遗嘱、社交恢复碎片 |
| 去中心化身份(DID)备份 | L2 | 根私钥碎片备份 |
| 实物交割与现金舱 | L3 | 法币代管、实物提取 |
| 智能信托继承协议 | L3 | 遗产自动释放 |

## 安全原则

1. **隐私优先**: 所有生物特征仅在本地处理，不上传原始数据
2. **密钥隔离**: 私钥永不上传，本地加密存储
3. **多签机制**: 高安全等级操作需多把钥匙联合签名
4. **社交恢复**: 支持多签方式恢复丢失的钥匙
