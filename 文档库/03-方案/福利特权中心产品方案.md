# 福利特权中心产品方案

## 一、方案概述
为 IM 开放服务平台建设「福利特权中心」，承载空投、持仓返利、互动激励等运营活动。核心目标：支持多实例部署、多链多钱包、活动多合约下发，并通过统一后台完成配置与分发。

## 二、整体流程

```
服务注册中心
    │
    ▼
产品启用福利特权服务
    │
    ▼
用户进入「服务」入口页
    │
    ▼
钱包绑定校验
    │
    ├── 未绑定 ──▶ 绑定引导弹窗 ──▶ 绑定自管钱包 ──▶ 按原目标进入
    │
    └── 已绑定
           │
           ├── 点击 IM 余额卡片 ──▶ 钱包服务页（本期占位）
           │
           ├── 点击「福利特权」大模块 ──▶ 进入福利特权首页
           │                                  │
           │                                  ├── 点击分类入口 ──▶ 分类方案列表页
           │                                  │
           │                                  └── 点击活动卡片 ──▶ 方案详情页
           │
           └── 点击子分类图标 ────────────▶ 直接进入分类方案列表页
                                                   │

                                            点击活动卡片 ──▶ 方案详情页
                                                   │
                                                   ▼
                                            查看合约列表
                                                   │
                                                   ▼
                                        领取 ──▶ 链上发放
```

## 三、外部入口设计（保留特权服务首页）

### 3.1 入口页定位
- **第零层：「服务」入口页**
  - 页面顶部标题为「服务」。
  - 顶部展示「IM 余额」钱包服务卡片，点击可进入钱包服务页（本期占位）。
  - 下方「服务入口」区域保留「福利特权」大模块，模块内包含空投 / 资产 / 互动三个子分类快捷入口。
  - 点击「福利特权」大模块进入福利特权首页；点击子分类图标可跳过首页，直接进入对应分类的方案卡片列表。
  - 福利特权首页作为列表聚合页继续保留，不被入口页替代。

### 3.2 钱包绑定校验
- 点击福利特权模块或子分类前，先检测当前钱包是否已绑定有效地址。
- **已绑定**：点击大模块进入福利特权首页，点击子分类图标直接进入对应分类方案列表页。
- **未绑定**：弹出绑定引导弹窗，引导用户绑定自管钱包（选择账户 + 链地址后确认绑定）。
- 平台托管钱包与外部绑定钱包本期暂不启用。

### 3.3 入口状态提示
- 入口页 header 显示「已绑定 / 未绑定」状态标签，便于用户感知。
- 福利特权首页保留，作为活动总览和分类入口，不被入口页替代。

## 四、方案内部多合约设计

### 4.1 方案与合约关系
- 一个福利方案可对应 **多个奖励合约**，解决同一活动在不同链或多个合约中分批发放的问题。
- **合约层**：记录合约地址、所属链、奖励币种、奖励数量、当前余额。
- **方案层**：记录方案名称、方案类型（空投 / 资产 / 互动）、活动说明、资格条件、规则说明、是否自动下发。
- 领取记录以「单合约」为维度，用户可对每个合约独立领取，也可一键领取全部未领取合约。

### 4.2 方案详情页
- **顶部**：活动标题、简介、标签卡片（精简展示）。
- **中部**：合约奖励列表，展示每个合约的：
  - 链名称
  - 合约地址（可复制）
  - 当前余额
  - 奖励金额
  - 领取按钮
- **底部固定操作栏**：「一键领取全部」，批量领取所有未领取合约。
- **下方折叠区**：方案详情、资格条件、规则说明、领取地址。

### 4.3 领取逻辑
- 支持**单个合约手动领取**。
- 支持**一键领取全部**未领取合约。
- 无需额外核验，点击即进入链上确认。
- 每个合约领取状态独立判断，全部合约领取完毕后活动标记为「已领取」。

### 4.4 统计维度
- 首页与分类页统计从「方案数量」改为「合约数量」：
  - 总合约数
  - 待领取合约数
  - 已领取合约数
- 币种明细仍展示各 Token 待领 / 已领金额。

## 五、钱包体系

| 钱包类型 | 说明 | 绑定方式 | 本期状态 |
| --- | --- | --- | --- |
| 自管钱包 | 用户本地多链多账户钱包 | 选择账户 + 链后确认绑定 | 启用 |
| 平台托管钱包 | 平台为用户生成并管理的高频交互地址 | 默认存在，一键使用 | 暂不启用 |
| 外部绑定钱包 | MetaMask、WalletConnect 等第三方钱包 | 调起连接授权 | 暂不启用 |

## 六、活动类型

| 类型 | 说明 | 领取方式 |
| --- | --- | --- |
| direct | 直接领取 | 用户手动点击领取，本期主要支持 |
| whitelist | 白名单核验后领取 | 由后台完成白名单校验并触发发放，前端展示为可领取状态 |
| auto | 自动下发 | 系统按周期自动发放，本期暂不支持 |

## 七、原型说明

原型文件：`福利中心entry.html`

- 默认打开为「未绑定」状态，便于演示绑定流程。
- 进入福利特权首页需先完成钱包绑定，本期绑定流程以自管钱包为主。
- 活动详情页展示多合约列表，支持单领 / 一键全领。
- 分类列表采用统一大小两列网格卡片，不再使用瀑布流。
- 原型中保留了平台托管与外部钱包的交互选项，实际本期仅启用自管钱包。
