## 背景与目标

安全保险库是IM开放服务生态中的高安全等级资产托管与鉴权框架。核心目标是解决Web3生态中批量注册、薅羊毛（女巫攻击）问题，通过"钥匙(鉴权)与保险柜解耦绑定"架构，为不同安全等级的资产和服务提供分层保护。

## 用户故事

- 作为IM用户，我希望绑定我的设备作为安全钥匙，以便领取高价值权益
- 作为IM用户，我希望我的资产被多层钥匙保护，以便在设备丢失时仍能找回
- 作为运营方，我希望确保每个权益只能被真实用户领取，以便防止批量薅羊毛

## 核心概念

| 概念 | 定义 |
|------|------|
| 钥匙(Key) | 鉴权凭证，用于验证用户身份和设备合法性 |
| 保险柜(Vault) | 托管容器，存放资产、权益或数据，需要特定钥匙组合才能开启 |
| 冷密钥(Cold Key) | 基于物理硬件特征生成的非对称密钥对，私钥永不上传 |
| 服务舱 | 特定业务场景下的保险柜实例，如虚拟权益舱、资产托管舱 |

## 非功能性需求

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| V-NFR-001 | 隐私保护 | P0 | 所有生物特征仅在本地处理，不上传原始数据 |
| V-NFR-002 | 密钥安全 | P0 | 私钥永不上传，本地加密存储 |
| V-NFR-003 | 防女巫攻击 | P1 | 确保同一物理设备无法批量创建有效身份 |
| V-NFR-004 | 社交恢复 | P2 | 支持多签方式恢复丢失的钥匙 |

## 技术约束

- 设备指纹采集需在本地沙盒完成，不得上传原始硬件信息
- 生物特征识别必须调用系统级API（iOS Secure Enclave / Android Biometric）
- 所有高安全等级操作需多把钥匙联合签名
