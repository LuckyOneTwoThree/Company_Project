## 1. 概述

### 1.1 背景

冷钱包是IM开放服务生态中面向C端用户的链上资产管理入口，作为福利特权中心的下游功能模块存在。用户通过福利特权中心绑定自管钱包后，可在冷钱包内查看资产、兑换代币（Swap）、领取测试代币（Faucet），后续还将扩展发送、接收等链上交互能力。

### 1.2 目标

- 为IM用户提供轻量级链上资产管理能力，无需切换到外部钱包App
- 通过Swap功能打通自主链代币（RC/USDRs/HRCs/RSTs）之间的兑换
- 通过Faucet功能为测试网用户提供测试代币领取渠道
- 作为福利特权中心的资产出口，领取的空投/返利代币在此展示和管理

### 1.3 范围

| 模块 | 本期MVP | 后续迭代 |
|------|---------|----------|
| 钱包首页（资产总览+代币列表） | ✅ | - |

### 3.3 Faucet代币领取（CW-FAUCET）

**功能描述**：用户每24小时可领取5 RC测试代币，展示资金池状态、冷却倒计时、Gas检测。

| 编号 | 需求描述 | 优先级 | 验收标准 |
|------|----------|--------|----------|
| CW-FAUCET-001 | 顶部代币卡片：展示领取代币（RC）、单次领取量（5.00 RC） | P1 | 视觉醒目，绿色渐变背景 |
| CW-FAUCET-002 | 资金池状态卡片：展示剩余量、进度条、已发放/总量、状态标签 | P1 | 进度条实时反映剩余比例，<20%显示"不足"红色 |
| CW-FAUCET-003 | 领取状态卡片：可领取时显示"已超过24小时，可立即领取" | P1 | 绿色"可领取"标签 |
| CW-FAUCET-004 | 冷却状态：不可领取时显示倒计时（HH:MM:SS）和进度条 | P1 | 灰色"冷却中"标签，按钮禁用显示倒计时 |
| CW-FAUCET-005 | Gas检测卡片：检测当前地址RC余额是否足够支付Gas | P1 | 余额充足显示绿色"充足"，不足显示红色提示 |
| CW-FAUCET-006 | Gas不足时由平台代发，无需用户支付手续费 | P2 | 提示文案"Gas不足时由平台代发" |
| CW-FAUCET-007 | 领取按钮：可领取时显示"领取 5.00 RC"，冷却中禁用 | P1 | 可点击时绿色渐变，禁用时灰色 |
| CW-FAUCET-008 | 领取执行弹窗：3步进度（资格校验→合约交互→链上确认），每步完成后打勾 | P1 | 每步约1s，全部完成约3s，成功后关闭弹窗 |
| CW-FAUCET-009 | 领取成功后：Toast提示、进入冷却倒计时、更新资金池余额 | P1 | 资金池减少5 RC，进度条同步更新 |
| CW-FAUCET-010 | 领取记录弹窗：右上角入口，展示最近领取记录（时间、金额、交易哈希） | P2 | 哈希支持复制，底部提示"仅显示最近记录" |
| CW-FAUCET-011 | 规则说明区：展示5条领取规则 | P2 | 固定文案，不可编辑 |

**Faucet规则（原型定义）**：

1. 每个地址每24小时可领取一次
2. 每次领取5 RC测试代币
3. Gas不足时由平台代发，无需手续费
4. 资金池余额不足时暂停领取
5. 禁止多地址套取，违规将被拉黑

```
钱包首页 (view-wallet)
  ├── → Swap页面 (view-swap)

  │     ├── 滑点设置弹窗 (sheet-swap-settings)

  │     └── 执行中弹窗 (sheet-swap-loading)

  └── → 币种详情页 (view-coin-detail)
        └── → Swap页面 (预选当前币种)
```

## 6. 数据模型

### 6.1 代币（Coin）

```typescript
interface Coin {
  symbol: string;       // 币种符号，如 "RC"
  name: string;         // 币种全名，如 "RC Token"
  balance: string;      // 持有量（格式化字符串）
  price: string;        // 单价（USD）
  change: string;       // 24h涨跌幅，如 "+2.1%"
  gradient: string;     // 图标渐变色CSS
  icon: string;         // 图标文字
  chain: string;        // 所属链，如 "自主链"
}
```

### 6.2 兑换汇率（Rates）

```typescript
// 二维映射：rates[支付币种][接收币种] = 汇率
type Rates = Record<string, Record<string, number>>;
```

### 6.3 Faucet状态

```typescript
interface FaucetStatus {
  claimable: boolean;        // 是否可领取
  cooldownEndsAt: number;    // 冷却结束时间戳（秒）
  poolBalance: number;       // 资金池剩余量
  poolTotal: number;         // 资金池总量
  claimAmount: number;       // 单次领取量
  gasBalance: number;        // 当前Gas余额
}
```
