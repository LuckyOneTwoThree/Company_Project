## 0. v2.1.1 补全说明(严格对齐 7 个渠道合约边界规则)

| 合约函数 | v2.1 状态 | v2.1.1 修正 |
|---------|----------|------------|
| `FixedPriceMarket.buyListed` | 详情页所有资产都显示"立即购买" | **CTA 按 data-channel 区分**:fixed→立即购买 / auction→参拍出价 / rental→确认承租 |
| `RentalChannel.rent` | 仅挂租方有 form-rental,承租方无确认弹窗 | **新增 modal-rent 承租确认弹窗**(含 ERC-4907 使用权风险提示 + 货款直付说明) |

| `AuctionHouse` 流拍分支 | 订单记录无流拍状态 | **新增流拍记录**(无出价或未达底价,SKU 解锁回卖家) |

## 0.1 v2.1 改动说明(对齐合约基准)

v2.0 在 4 Tab 架构下精简了入口,但 4 Tab 中「搜索/活动」均为 P2 占位,浪费导航位;且租赁(RentalChannel)原排期为 P3,合约层已于 2026-07-21 确认提前至 P1。v2.1 在此基础上做以下调整:

| 问题 | v2.0 状态 | v2.1 修正 |
|------|----------|----------|
| 底部 4 Tab 臃肿 | 市场/搜索/活动/我的 4 项,搜索/活动为占位 | **去掉底部 Tab**,市场为单视图,「我的」改为右上角入口 |
| 渠道切换不直观 | 渠道筛选藏在抽屉二级筛选内 | **首页增加渠道分类快捷切换**(全部/一口价/拍卖/租赁),4 项单选 chip |
| 租赁排期滞后 | 租赁 🔒P3,筛选抽屉内禁用 | **租赁提前至 P1**,挂单弹窗新增 form-rental,「我的出租」独立 Tab |
| 赠送语义混淆 | 赠送与一口价/拍卖并列在挂单弹窗 | **赠送移出挂单弹窗**,保留在短号中心/商品详情页入口(订单中心仍可见 channelId=1 记录) |
| 拍卖结算/退款缺位 | modal-bid 仅出价,无结算/退款入口 | **补强 settleAuction / withdrawRefund / forceSettle 归属说明** |
| 卡片缺渠道标识 | 卡片仅显示资产类型 tag,无渠道区分 | **卡片左上角增加渠道角标**(🏷一口价 / 🔨拍卖 / 🔑租赁) |

**对齐主流市场心智**:OpenSea / Blur 移动端一致采用「市场浏览为主视图 + 个人中心右上角入口 + 挂售藏在资产详情内」模式。渠道快捷切换让用户直接按成交模式筛选,比 Tab 切换更贴合交易心智。

## 0.1 v2.0 重写背景(历史)

v1.0 原型采用「我要卖 / 我要买 / 我的订单」三视图顶部 Tab,默认进入「我要卖」(个人资产视角),并将 miner 运营设置放在 C 端 ⚙ 入口。该设计存在方向性偏差:

| 问题 | v1.0 状态 | v2.0 修正 |
|------|----------|----------|
| 默认视角偏差 | 「我要卖」为默认,违背"市场以买为主"心智 | 默认进入「市场」浏览(买方视角) |
| 挂售入口位阶过高 | 顶部 Tab 与市场浏览并列 | 挂售作为次级入口,藏在「我的 → 资产详情」内 |
| C 端混入运营设置 | ⚙ 入口暴露渠道开关/手续费/系统拍卖 | **完全移除**,运营能力下沉至 B 端管理后台 |
| 资产品类单一 | 仅短号(靓号/免费号) | 扩展为 7 类:靓号/免费号/实物/虚拟/服务/保密 |

**参考主流项目**:OpenSea、Blur、Magic Eden、LooksRare——一致模式为「市场浏览为主视图 + 底部 Tab 导航 + 个人中心独立入口 + 挂售藏在资产详情内」。

### 2.2 关键交互细节

#### 2.2.0 渠道分类快捷切换(v2.1 新增 · 一级筛选)

- **位置**:`header-market` 搜索栏下方,资产类型 chip 上方,横向滚动(`hide-scrollbar`)
- **项数**:4 项(全部 / 🏷 一口价 / 🔨 拍卖 / 🔑 租赁)
- **交互**:单选互斥,选中态 indigo-600 实心,未选中 slate-100 灰底
- **切换函数**:`switchChannel(channel)`,根据卡片 `data-channel` 属性过滤 `#market-grid` 下的卡片
- **效果**:点击 chip 即时过滤市场挂单(按成交模式),无需打开抽屉
- **与资产类型 chip 关系**:两者可叠加筛选(渠道 × 资产类型双维度)

#### 2.2.1 顶部资产类型 chip(二级筛选)

- **位置**:`header-market` 渠道分类 chip 下方,横向滚动(`hide-scrollbar`)
- **项数**:7 项(全部 / 💎靓号 / 🎁免费号 / 🛒实物 / 🎫虚拟 / 🛎️服务 / 🔒保密)
- **交互**:单选互斥,选中态 indigo-600 实心,未选中 slate-100 灰底
- **切换函数**:`switchType(type)`,根据 type 过滤网格
- **效果**:点击 chip 即时过滤市场挂单,无需打开抽屉

#### 2.2.2 筛选抽屉(三级筛选)

- **入口**:搜索栏右侧 ⚙ 按钮 → `openFilterDrawer()`
- **结构**(自上而下):
  - 渠道(4 选,默认勾选一口价;拍卖可勾;荷兰拍🔒P3 禁用;**租赁 v2.1 提前至 P1 可勾**)
  - 价格区间(USDRs · 最低—最高 数字输入)
  - 网络(全部 / OBChain / Ethereum / Arbitrum · 单选 pill)
  - 资产状态(立即可购买 / 即将结束(24h) / 有出价记录 · 多选 checkbox)
- **底部**:重置 + 应用(N) 双按钮,应用按钮显示实时结果数
- **关闭**:遮罩点击 / ✕ / 应用按钮

#### 2.2.3 排序抽屉

- **入口**:排序条「最新上架 ▾」→ `openSortDrawer()`
- **5 个选项**:最新上架(默认✓) / 价格从低到高 / 价格从高到低 / 即将结束 / 出价最多
- **交互**:单选,选中后立即关闭抽屉 + 更新排序条文案 + 刷新网格

#### 2.2.4 资产详情页(全屏)

- **入口**:任意市场挂单卡片或「我的资产」卡 → `openListingDetail(id)` / `openAssetDetail(id)`
- **结构**:
  - 资产预览大图区(`gradient-*` h-64,展示号码或品类图标)
  - 基本信息卡(名称 + 元数据 + 类型 tag + 价格 + 卖家短地址)
  - 3 Tab 详情(属性 / 流转历史 / 挂单深度)
  - 底部固定 CTA(根据 `isOwner` 切换)
- **CTA 切换逻辑**:
  - **非持有者**:`[立即购买](indigo 大按钮)`(拍卖场景为 `[出价竞争]`)
  - **持有者**:`[挂售流转](indigo 大按钮)`
- **3 Tab 内容**:
  - 属性:类型/特征/倍率/位数/网络/持有起始(6 项 2 列网格)
  - 流转历史:纵向时间线(成交 + 一级购买)
  - 挂单深度:当前挂单 + 出价记录(拍卖场景)

#### 2.2.5 挂单弹窗(`modal-list` · v2.1 调整)

- **入口**:仅在「我的 → 我的资产」卡片上的「挂售」按钮(无 FAB/顶部 Tab)
- **结构**:
  - 渠道选择(3 列 v2.1):🏷 一口价(默认) / 🔨 拍卖 / 🔑 租赁
  - 资产信息(只读,灰底卡)
  - 渠道参数表单(根据选中渠道切换)
  - 通用风险提示(资产锁定 + 不触发奖励)
  - PIN 码签名
  - 取消 + 确认(文案/颜色随渠道切换)
- **渠道切换逻辑**(`selectChannel(channel)`):
  | 渠道 | 表单 ID | 确认按钮文案 | 按钮色 |
  |---|---|---|---|
  | 一口价 fixed | `form-fixed` | 确认挂售 | indigo-600 |
  | 拍卖 auction | `form-auction` | 确认挂拍 | pink-600 |
  | 租赁 rental(v2.1 替换 gift) | `form-rental` | 确认挂租 | amber-600 |
- **渠道参数**:
  - 一口价:收款币种 + 价格 + 过期时间 + 费用预估(0% 手续费,合约无 setFeeBps)
  - 拍卖:起拍价 + 底价 + 时长 + 手续费提示(2.5%)
  - 租赁(v2.1):租客地址+扫码 + 收款币种 + 每周期租金 + 周期长度(1小时/1天/7天/30天)+ 购买周期数 + 独占模式开关(默认是)+ 费用预估(无手续费)+ 风险提示(lockSku/使用权分离/endRental)
- **v2.1 移除项**:`form-gift`(赠送表单)已删除,赠送入口移至短号中心/商品详情页

#### 2.2.6 购买确认弹窗(`modal-buy`)

- **入口**:详情页「立即购买」
- **结构**:
  - 资产信息(灰底 · 名称 + 元数据 + 卖家 + 渠道 + 剩余有效期)
  - 支付明细(浅 indigo 底 · 支付金额 / 手续费 / Gas / 合计)
  - 风险提示(资产过户 + 不触发关系绑定 铁律)
  - PIN 码 + 取消 + 确认购买(emerald-600)

#### 2.2.7 出价弹窗(`modal-bid` · v2.1 补强)

- **入口**:拍卖资产详情页「出价竞争」
- **结构**:
  - 拍卖信息(起拍价 / 当前最高价 emerald 高亮 / 出价者 / 剩余时间红色 / 出价次数)
  - 出价历史(font-mono · 时间 / 出价者 / 金额,当前最高 emerald)
  - 出价输入(默认值 = 当前最高 + 10,提示"≥ X USDRs"和"托管至合约")
  - **v2.1 新增**:拍卖结算/退款归属说明
    - `settleAuction()`:任何人可在拍卖结束后点击结算 → 最高出价者获资产 + 卖家收款
    - `withdrawRefund()`:出价被超的失败者主动调取回退款
    - `forceSettle()` / `forceCancel()`:miner 多签强制结算/取消(异常场景)
  - 风险提示 + PIN + 确认出价(pink-600)

## 6. 使用说明

### 6.1 预览

直接用浏览器打开 `resale_market_demo.html` 即可预览,无需任何依赖(Tailwind 通过 CDN 加载)。

### 6.2 交互测试路径(v2.1 · 共 12 项)

1. **首屏(市场浏览)**:打开页面 → 默认进入市场视图(无底部 Tab)→ 查看 Featured 推荐 + 8 个资产卡片(左上角带渠道角标)
2. **渠道分类快捷切换(v2.1)**:点击「🔨 拍卖」chip → 网格过滤出拍卖挂单 → 点击「全部」恢复 → 点击「🔑 租赁」过滤出租赁挂单
3. **资产类型筛选**:点击资产类型 chip「💎 靓号」→ 与渠道筛选叠加过滤 → 点击「全部」恢复
4. **二级筛选**:点击搜索栏右侧 ⚙ → 抽屉弹出 → 切换渠道(租赁已可勾)/网络 → 点「应用(N)」
5. **排序**:点击排序条「最新上架 ▾」→ 抽屉弹出 → 选「价格从低到高」
6. **资产详情(非持有者)**:点击任一市场挂单卡片 → 全屏详情页 → 查看属性/流转历史/挂单深度 → 底部「立即购买」
7. **进入我的(v2.1)**:点击 header 右上角「👤我的」→ 进入「我的资产」全屏页 → 查看资产概览卡(4 列含出租中)
8. **我的子 Tab(v2.1)**:在「我的」内切换「我的资产 / 我的挂单 / 我的出租 / 订单记录」4 个子 Tab → 点击「我的出租」查看 VIP 季卡租赁卡
9. **挂单(卖家)**:在「我的资产」点击任一资产卡上的「挂售」按钮 → 弹起挂单弹窗 → 切换渠道(🏷一口价 / 🔨拍卖 / 🔑租赁)→ 确认按钮文案/颜色同步切换
10. **资产详情(持有者)**:点击「我的资产」卡片本体 → 进入详情页 → 底部 CTA 切换为「挂售流转」
11. **购买确认**:在非持有者详情页点击「立即购买」→ 弹起支付确认弹窗
12. **出价 + 结算(v2.1)**:在拍卖资产详情页点击「出价竞争」→ 弹起出价弹窗(含出价历史 + v2.1 结算/退款归属说明)→ 查看底部「拍卖结算」按钮区
13. **结束租赁(v2.1)**:在「我的出租」点击 VIP 季卡租赁卡上的「结束租赁」→ 触发 endRental 二次确认
14. **退出我的(v2.1)**:点击 header 左上角「←」→ exitMine() 返回市场浏览
15. **运营设置已移除**:确认页面无 ⚙ 设置入口(v2.0 关键改动)
16. **底部 Tab 已移除(v2.1)**:确认页面无底部 4 Tab 栏(v2.1 关键改动)

### 6.3 适配

原型固定 390×844(iPhone 12 Pro 尺寸),与短号中心/Node 框架一致。可在桌面浏览器用 DevTools 切到移动视图查看。
